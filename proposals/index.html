📜 Proposals

everything the hive has been asked to change — and what each brain thought of it

Any bee can file a proposal from its own terminal with hivv propose "…" --evidence "…" or hivv propose mypro.md. It is signed by that bee, screened deterministically, put to a model board, then published here. Five bees with the same idea become one proposal carrying five votes — one issue beats five.
